# Configuration Reference

LITEPLOY is configured via environment variables.

---

## ⚙️ Environment Variables

| Variable | Default Value | Description |
|---|---|---|
| `LITEPLOY_ADDR` | `:8080` | Network address and port LITEPLOY listens on. |
| `LITEPLOY_DATA_DIR` | `./data` | Filesystem path for application & deployment JSON state. |
| `LITEPLOY_CADDY_ADMIN` | `http://localhost:2019` | Caddy Admin API endpoint URL for reverse proxy updates. |
| `LITEPLOY_DOCKER_HOST` | *(unix socket)* | Docker daemon socket address (e.g. `unix:///var/run/docker.sock`). |
| `LITEPLOY_SESSION_SECRET` | *(autogenerated in dev)* | 32+ character secret used to sign session cookies. |
| `LITEPLOY_SESSION_MAX_AGE` | `24h` | Session duration before requiring re-login. |
| `LITEPLOY_LOG_LEVEL` | `info` | Logging verbosity (`debug`, `info`, `warn`, `error`). |
| `LITEPLOY_LOG_JSON` | `false` | Enable structured JSON logging (`true` or `false`). |
| `LITEPLOY_DEV_MODE` | `false` | Enable developer mode (ephemeral session secret). |
| `LITEPLOY_CONCURRENT_BUILDS`| `1` | Maximum concurrent deployment builds allowed in pool. |
| `LITEPLOY_GIT_TIMEOUT` | `10m` | Maximum time allowed for git repository clones. |
| `LITEPLOY_BUILD_TIMEOUT` | `15m` | Maximum time allowed for Docker builds. |

---

## 📁 Filesystem Layout under `LITEPLOY_DATA_DIR`

```
/var/lib/liteploy/data/
├── applications/        # JSON application metadata (app-001.json, etc.)
├── state/               # Deployment build logs and working directories
├── config/              # User account credentials (users.json)
└── secrets/             # HMAC signing key
```
